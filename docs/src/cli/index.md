The `dit` command line is the primary tool for managing repositories and
commits. While there are a number of detailed subcommands, there are some
global options as well.

> **Note:**
> The `--help` option can be used to provide more detail about subcommands
> and their options, such as `dit run --help` or `dit remote --help`.
>

## Syntax

```bash
dit --help
dit --version
dit subcommand ...
```

## Options

--version       Display the dit version and exit.
--help, -h      Display available subcommands.
