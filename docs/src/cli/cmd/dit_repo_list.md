## dit repo list

List repositories on the server

### Synopsis

List all repositories on a dit remote server. Use --org to filter by organization.

```
dit repo list [flags]
```

### Options

```
  -h, --help            help for list
      --org string      Filter by organization
      --server string   Server URL
```
