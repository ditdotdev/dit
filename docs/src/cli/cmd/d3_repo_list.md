## d3 repo list

List repositories on the server

### Synopsis

List all repositories on a datadatdat remote server. Use --org to filter by organization.

```
d3 repo list [flags]
```

### Options

```
  -h, --help            help for list
      --org string      Filter by organization
      --server string   Server URL
```
