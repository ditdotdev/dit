## d3 repo delete

Delete a repository from the server

### Synopsis

Delete a repository from the specified organization on a datadatdat remote server.

```
d3 repo delete <org> <repo> [flags]
```

### Options

```
      --force           Skip confirmation
  -h, --help            help for delete
      --server string   Server URL
```
