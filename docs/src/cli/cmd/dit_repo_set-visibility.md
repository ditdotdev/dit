## dit repo set-visibility

Set a repository's visibility (public or private)

### Synopsis

Change whether a repository is public or private on a dit remote server. Specify exactly one of --private or --public.

```
dit repo set-visibility <org> <repo> [flags]
```

### Options

```
  -h, --help            help for set-visibility
      --private         Make the repository private
      --public          Make the repository public
      --server string   Server URL
```
