## dit org update

Update an organization's display name or description

### Synopsis

Update an organization's display name and/or description on a dit remote server. Specify at least one of --display-name or --description.

```
dit org update <org-name> [flags]
```

### Options

```
      --description string    New description for the organization
      --display-name string   New display name for the organization
  -h, --help                  help for update
      --server string         Server URL
```
