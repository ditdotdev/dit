## d3 checkout

Checkout a specific commit

```
d3 checkout [REPOSITORY] [flags]
```

### Options

```
  -c, --commit string   commit to checkout
  -h, --help            help for checkout
  -t, --tags strings    tag to filter latest commit, if commit is not specified
```
